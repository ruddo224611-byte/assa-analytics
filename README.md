# 아싸 상권분석 (assa-analytics)

자영업 창업 예정자를 위한 **상권 데이터 분석 서비스**입니다.
"이 자리에 이 업종, 괜찮을까?" 라는 의사결정을 공공데이터 기반으로 돕습니다.

자매 사이트 [assasup.com](https://assasup.com) 과 같은 브랜드의 신규 프로젝트이며,
나중에 **analytics.assasup.com** 서브도메인으로 연결 예정입니다.

## 기술 스택

- **Next.js 14** (App Router)
- **TypeScript** + **Tailwind CSS**
- **Pretendard** (본문) + **Gmarket Sans** (로고)
- **Vercel** 배포 예정

## 개발 단계

**Phase 0 진행 중** — 초기 셋업, 디자인 시스템, 플레이스홀더 홈.

## 데이터 소스

- [공단 상권정보 Swagger](https://infuser.odcloud.kr/oas/docs?namespace=15083033/v1)
- [공공데이터포털 (data.go.kr)](https://www.data.go.kr)

## 실행 방법

```bash
cd web
npm install
npm run dev
```

`http://localhost:3000` 에서 확인.
