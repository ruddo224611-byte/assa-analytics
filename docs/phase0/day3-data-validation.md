## TASK 1 — 국세청 100대 생활업종 사업자현황

### 1-1. 소스

- **공공데이터포털 15061118** — 국세청_사업자현황_100대 생활업종
- 페이지: https://www.data.go.kr/data/15061118/fileData.do
- 최신 기준: **2025-08-31** (월 단위 갱신)
- 직접 다운로드 URL (페이지 HTML 에서 추출한 atchFileId):

```
https://www.data.go.kr/cmm/cmm/fileDownload.do?atchFileId=FILE_000000003620844&fileDetailSn=1&insertDataPrcus=N
```

- 파일 포맷: CSV, 인코딩 **EUC-KR (CP949)**, 약 **953 KB / 24,481 라인**

### 1-2. 컬럼 & 규모

| 컬럼 | 의미 |
|---|---|
| 업종 | 100개 표준 업종 중 하나 (예: 커피음료점, 한식음식점) |
| 시도 | 광역시·도 (17개) |
| 시군구 | 기초지자체 |
| 당월 | 기준월(2025-08) 사업자 수 |
| 전월 | 2025-07 사업자 수 |
| 전년동월 | 2024-08 사업자 수 (전년 대비 증감 계산용) |

- **업종 수:** 정확히 **100개** ✓
- **(시도, 시군구) 조합:** **256개** (100개 업종이 모든 시군구에 다 존재하진 않음 — 시골 시군구는 pc방·네일샵 등 0건으로 빠지기도)
- 제공 형태: 현재 활성 사업자 수(stock)만. **개업/폐업 분리 없음** (단, 15048949 `신규사업자_업종별 월별` 이 별도 데이터셋으로 존재 → 개업수만 월별로 추적 가능)

- 미용실·한식은 소폭 증가세

### 1-4. 🟢 판정 — 즉시 ETL 투입 가능

**장점:**
- 무료·로그인 불필요·공식 월 단위 갱신
- 100개 업종 리스트가 그대로 MVP 의 **업종 드롭다운 마스터** 가 될 수 있음
- 시군구 단위 추이(당월·전월·전년동월) 로 트렌드 카드 바로 구성 가능

**주의사항 & 후속 조치:**
1. 헤더의 `당월` 은 기준일 파일명(`_20250831`) 과 비교해서 매번 절대 연월을 별도 보관해야 함 (CSV 자체에 연월이 없음 — **파일명을 메타로 함께 기록 필수**)
2. 인코딩 EUC-KR → `scripts/lib/encoding.ts` 의 `decodeEucKrResponse` 사용
3. **신규 사업자(개업) 시계열** 이 필요하면 15048949 (업종별 월별 신규 사업자) 를 추가로 활용신청 대상 후보
4. 행정동 단위가 아니라 **시군구 단위** 라는 한계 — 같은 "강남구" 안에서 역삼동 vs 압구정동 차이를 NTS 단독으로는 구분 못 함. 행정동 해상도는 상가 반경 API(B553077) + 주민등록 인구 조합에서 확보

### 1-5. MVP 활용 매핑

| MVP 기능 | NTS 활용 범위 |
|---|---|

| #2 경쟁 업체 분석 | 🟡 "강남구에 커피숍 1,375개" 같은 거시치는 제공 가능. 정확한 반경 내 카운트는 여전히 B553077 필요 |
| #1 리포트 "업종 메타" | 🟢 사이드바용 "전국/시군구 대비 이 지역의 밀집도 퍼센타일" 등에 바로 투입 |

### 2-2. 다운로드 경로의 함정

data.go.kr 의 `selectFileDataDownload.do` 에 POST 했을 때 돌아온 JSON 메타:

```json
{
  "atachFileYn": "N",          // 첨부파일 없음
  "atchFileId": null,
  "dataUrl": "https://www.reb.or.kr/r-one/portal/stat/easyStatPage/T241873134863890.do",
  "detailUrl": "/data/15069843/fileData.do"
}
```

→ **data.go.kr 에서는 메타만 카탈로그화** 하고 **실제 파일은 R-ONE 포털에서만 받을 수 있음**.

R-ONE 포털의 경로:
- 사이트: https://www.reb.or.kr/r-one/portal/stat/easyStatPage/T241873134863890.do
- 다운로드: 페이지 내 "엑셀전체받기" 버튼 (AJAX 호출, JS 동적 생성)
- 제공 포맷: XLS / CSV / JSON / XML / TXT

**공공데이터포털 키로 R-ONE 파일 접근 시도 → `401 유효하지 않은 인증키` 확인.**

### 2-3. 자동화 옵션

**A. R-ONE OpenAPI 활용신청 (권장)**
- 주소: https://www.reb.or.kr/r-one/openapi/openApiIntroPage.do
- 별도 회원가입·신청 필요, 발급까지 영업일 기준 1~2일
- 장점: cron 기반 자동 갱신 가능
- 추가 환경변수 필요: `REB_API_KEY` (향후 `.env.local` 에 추가)

**B. 수기 다운로드 + 저장소 커밋 (백업 루트)**
- Phase 1 ETL 스케줄에서 월 1회 수동 업데이트
- 분기 갱신이라 부담 크지 않음 (연 4회)

### 2-4. 확인 항목 vs 실제 결과

| 기획한 확인 항목 | 결과 |
|---|---|
| 층별 임대료 (1층/2층/지하) 실제 수치 | 🟡 데이터셋 이름상 제공 확실. 샘플은 R-ONE 접근 후 확인 가능 |
| 지역 단위 (상권 / 시군구 / 시도) | 📄 R-ONE 기준으로는 **전국 주요 상권** 단위 (강남대로, 명동, 홍대합정 등) + 시도 요약 |
| 서울시 강남구 실측치 | 🟡 R-ONE 페이지에서 UI 열람 가능. CSV 자동 추출은 OpenAPI 승인 후 |

### 2-5. 🟡 판정 — Phase 1 전 R-ONE 경로 확보 필요

**판단:** 데이터 자체의 품질·갱신 주기는 MVP 요구에 충분함. **막힌 건 접근 경로뿐**.

액션 아이템:
1. ⬜ R-ONE OpenAPI 활용신청 즉시 제출 (1~2영업일)
2. ⬜ 승인 전까지는 `docs/phase0/samples/rent-sample.csv` 를 placeholder 로 유지
3. ⬜ 승인 후 `scripts/fetch-reb.ts` 를 실제 호출 로직으로 교체 + `REB_API_KEY` 환경변수 추가

### 2-6. MVP 활용 매핑

| MVP 기능 | REB 활용 범위 |
|---|---|
| #4 상권 벤치마크 임대료 | 🟢 핵심 소스. 상권·분기·층별 평균임대료 직접 제시 가능 |
| #5 창업 시뮬레이터 BEP | 🟢 고정비 입력값으로 월 임대료 기준값 제공 |
