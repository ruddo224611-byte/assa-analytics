# Phase 3 Day 3 — 점수 알고리즘 정밀화 (시군구 분위)

**날짜:** 2026-04-27
**작업:** 운영자 피드백 — 점수 4종이 강남구에서 거의 다 0~30점 (의미 X). 시군구 분위 기반으로 재설계.

---

## 결과

🟢 **점수 차별성 압도적 ↑.** 강남구 안에서 행정동·업종 비교 가능.

| 행정동 | 이전 (Day 2 절대) | 새 (Day 3 분위) | 톤 변화 |

| 역삼1동 | 27 | **46** | 우려 → 보통 |

### 새 알고리즘 핵심

- **시군구 안 percentile rank** 기반 (절대값 → 상대 위치)
- **100 = 시군구 1위**, 50 = 시군구 평균, 0 = 꼴찌
- 사용자 의도 ("이 자리, 강남구 안에서 어디쯤?") 와 일치
- 점수 풀이도 명시: "**강남구 안에서** 사람 많은지 / 비어있는지 / 저렴한지 / 전체 평가"

---

## 발견 — 3가지

### 1. ✅ 절대값 → 시군구 분위 = 차별성 명확
이전: 강남구 행정동 모두 종합 20-30 (우려) — 차이 안 보임
새: 38~75 (우려·보통·양호 다 등장) — **운영자가 "강남구 안에서 어디 차릴지" 한눈에 보임**

### 2. ✅ AI 가 "1위" 같은 상대 위치 언급
LLM prompt 의 비교 컨텍스트 (Day 2 도입) 와 새 점수가 결합되어:
- "강남구 내 커피음료점 적합도 1위를 차지한 건..."
- "30~40대 비율은 시군구 평균과 정확히 같아요"
- "역설적으로, 경쟁이 심한 이유가 곧 수요의 이유"

### 3. ⚠️ 단점: 시군구 간 비교 불가
강남구 1위 (100) ≠ 도봉구 1위 (100) 의 절대 비교는 안 됨. 즉 "강남 75점" 과 "도봉 75점" 의 의미가 다름.

→ 운영자 의도가 **"이 시군구 안에서 어디 차릴지"** 라 분위 기준이 맞음. 시군구 간 비교는 Phase 4 (비교 모드) 에서 별도 화면 (예: 시군구 평균 절대값) 으로 다룸.
