## 발견 — 3가지

### 1. ⚠️ SBIZ API 429 rate limit 발견 (분당/시간 한도)
경기도 화성시 병점구 빌드 중 `HTTP 429: API token rate limit exceeded`. 그 이후 9개 시군구 빌드 실패.

지금까지 누적 호출 = Day 1+2+3+4 합쳐 ~3,500회 (일 한도 10,000 의 35%). **일 한도가 아니라 분당/시간 한도** 임. 일 한도 외에도 더 빡빡한 한도 존재.

→ **lib/sbiz 의 callWithRetry 강화:**
- 403 (캐시 활성화) — 60초 1회 재시도 (기존)
- **429 (rate limit) — 60→120→180초 점진 백오프 최대 3회 재시도 (신규)**

→ 누락 9개 시군구 (화성시 병점구·동탄구, 광주시, 양주시, 포천시, 여주시, 연천군, 가평군, 양평군) **모두 재빌드 성공** (재시도 1회만 발생).

### 2. NTS 시군구명 사전 검증 통과 (세종 사고 재발 방지 효과)
`build-reference-provinces.ts` 에 NTS 시군구 set 사전 검증 로직 추가. **도 9개 179 시군구 모두 NTS 와 일치** (세종처럼 따로 fix 필요한 케이스 0).

특히 경기도의 "수원시 장안구" 같이 시·구 합본 시군구명이 NTS 와 정확히 매칭되는 것 확인.

### 3. PR diff 가 **123 파일 / 1.4M 줄 추가** 로 커짐
서울 25 + 광역시 51 + 도 5 = 시군구 합본 파일 122개. PR 검토 시 모든 파일 보긴 어려움 — 위 샘플 표만 봐도 직관 검증 가능. (각 파일이 시군구 1 nested JSON 이라 변동 추적은 시군구 단위로 가능)
